# Balloon Pop 🎈

A cute 2D balloon popping game made with Unity.

## 🎮 Play the Game

[Play Balloon Pop in your browser](https://malak-fatoum.github.io/Balloon-Pop-WebGL/)

## ✨ Features

- Random balloon spawning
- Multiple balloon types
- Score system
- 60-second timer
- Pop animation and sound effects
- Game Over and Retry system

## 🛠 Built With

- Unity
- C#
- TextMeshPro
- Unity Input System
